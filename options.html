URL Saver for Supabase

One click on the toolbar icon saves the current page's URL and title to your Supabase database.

Not configured

Use the publishable key (or the legacy anon key), never a service_role or sb_secret_ key.

Set up Supabase

First time here? Four short steps.

  1. Create a Supabase project

    Sign in and create a free project at supabase.com/dashboard.

  2. Create the table

    Open the SQL editor, paste the schema below, and run it. It creates public.saved_urls with Row Level Security and insert-only access for the public key. 

    Loading schema…

  3. Copy your API credentials

    In Settings → API Keys, copy the Project URL and the publishable key (or the legacy anon key) into the form above.

  4. Save pages with one click

    Pin the extension, then click its toolbar icon on any page. A green ✓ badge means the row was inserted. Check your data in the table editor.
